Solution 3.1.5.6.1.

SOLUTION (a) If a function is linear, then the differences in successive function values will be constant. If a function is exponential, the ratios of successive function values will remain constant. Now
\begin{equation*} h(1) - h(0) = 8 - 14 = -6, \end{equation*}
and
\begin{equation*} h(2) - h(1) = 2 - 8 = -6 \end{equation*}
(and similarly for the remaining intervals). Thus, \(h(x)\) is linear. We know that \(h(x)\) is linear, so
\begin{equation*} h(x) = m\,x + b \end{equation*}
for some constants \(m\) and \(b\text{.}\) We know that \(h(0) = 14\text{,}\) so
\begin{equation*} 14 = m\cdot 0 + b = b, \end{equation*}
and \(b = 14\text{.}\) Then \(h(1) = 8\text{,}\) so
\begin{equation*} 8 = m\cdot 1 + 14, \end{equation*}
so \(m = 8 - 14 = -6\text{,}\) and we have
\begin{equation*} h(x) = -6\,x + 14. \end{equation*}
(b) As before, if a function is linear, then the differences in successive function values will be constant. If a function is exponential, the ratios of successive function values will remain constant. Now
\begin{equation*} i(1) - i(0) = 12.6 - 14 = -1.4, \end{equation*}
and
\begin{equation*} i(2) - i(1) = 11.34 - 12.6 = -1.26 \end{equation*}
(and similarly for the remaining intervals). Thus, \(i(x)\) is not linear. On the other hand,
\begin{equation*} \begin{aligned} \frac{i(1)}{i(0)} \amp = 0.9\\ \frac{i(2)}{i(1)} \amp = 0.9 \end{aligned} \end{equation*}
(and similarly for the remaining intervals). Thus \(i(x)\) is exponential. We know that \(i(x)\) is linear, so
\begin{equation*} i(x) = a\,b^x \end{equation*}
for some constants \(a\) and \(b\text{.}\) We know that \(i(0)=14\text{,}\) so
\begin{equation*} \begin{aligned} 14 \amp = i(0)\\ 14 \amp = ab^0\\ 14 \amp = a(1). \end{aligned} \end{equation*}
Thus, \(a=14\text{.}\) Also
\begin{equation*} \begin{aligned} 12.6 \amp = i(1)\\ 12.6 \amp = 14\,b. \end{aligned} \end{equation*}
Thus \(b = 0.9\text{,}\) and we have
\begin{equation*} i(x) = 14\cdot 0.9^x. \end{equation*}
