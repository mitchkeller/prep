If we consider an exponential function \(f\) with a growth factor \(b > 1\text{,}\) such as the function pictured in Figure 3.1.8, then the function is always increasing because higher powers of \(b\) are greater than lesser powers (for example, \((1.2)^3 \gt (1.2)^2\)). On the other hand, if \(0 \lt b \lt 1\text{,}\) then the exponential function will be decreasing because higher powers of positive numbers less than \(1\) get smaller (e.g., \((0.9)^3 \lt (0.9)^2\)), as seen for the exponential function in Figure 3.1.9.
