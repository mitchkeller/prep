SOLUTION This function resembles a cosine curve in that it attains its minimum (not midline) when \(x = 0\text{.}\) Since the value is at its minimum (not maximum) at \(x = 0\text{,}\) we need to use the formula \(f(x) = - \cos{(x)}\text{.}\) We know that the smallest value it attains is \(0\text{,}\) that its midline is \(y = 14\text{,}\) so its amplitude is \(14\) as well. Thus in the equation \(f(x) = -A \cos{(Bx)} + k\) we know that \(A = 14\) and \(k = 14\text{.}\) Since the graph has a period of \(10\text{,}\) the value for \(B = \frac{2 \pi}{\mbox{period}} = \frac{2 \pi}{10} = \frac{\pi}{5}\text{.}\) Finally we have a formula:
\begin{equation*} f(x) = 14-14 \cos{ \left( \frac{\pi}{5} x \right) }. \end{equation*}
