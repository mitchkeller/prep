Solution 4.5.5.2.1.

SOLUTION (a) Since \(\csc{ ( \theta ) } = \frac{1}{\sin{ ( \theta )}}\text{,}\) we begin by using the Pythagorean Identity to find \(\sin{ ( \theta ) }\text{.}\) Since \(\cos^2{ ( \theta )} + \sin^2{ ( \theta ) }=1\text{,}\) we have
\begin{equation*} \begin{array}{rcl} \left( \frac{1}{8} \right)^2 + \sin^2{ ( \theta ) } \amp = \amp 1 \\[1ex] \sin^2{ ( \theta )} \amp = \amp 1 - \frac{1}{64} \\[1ex] \sin{ ( \theta ) } \amp = \amp \pm \sqrt{ \frac{63}{64} }. \end{array} \end{equation*}
Since \(0 \le \theta \le \frac{\pi}{2}\text{,}\) \(\sin{ ( \theta ) } \ge 0\text{,}\) so \(\sin{ ( \theta ) } = \sqrt{ \frac{63}{64}}\text{.}\) Thus, \(\csc{ ( \theta )} = \sqrt{ \frac{64}{63}}\text{.}\) (b) Since \(\cot{ ( \theta ) }= \frac{ \cos{ ( \theta ) }}{\sin{ ( \theta ) }}\text{,}\) we have \(\cot{ ( \theta ) } = \frac{1/8}{\sqrt{63/64}} = \frac{1}{\sqrt{63}}\text{.}\)
