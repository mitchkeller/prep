From an algebraic point of view, horizontal translations are slightly more complicated than vertical ones. Given \(y = f(x)\text{,}\) if we define the transformed function \(y = h(x) = f(x-b)\text{,}\) observe that

\begin{equation*} h(x+b) = f( (x+b) - b ) = f(x)\text{.} \end{equation*}

This shows that for an input of \(x+b\) in \(h\text{,}\) the output of \(h\) is the same as the output of \(f\) that corresponds to an input of simply \(x\text{.}\) Hence, in Figure 1.8.3, the formula for \(h\) in terms of \(f\) is \(h(x) = f(x-2)\text{,}\) since an input of \(x+2\) in \(h\) will result in the same output as an input of \(x\) in \(f\text{.}\) For example, \(h(2) = f(0)\text{,}\) which aligns with the graph of \(h\) being a shift of the graph of \(f\) to the right by \(2\) units.
