Solution 4.4.4.1.1.

SOLUTION a) We begin by using the Pythagorean Identity to find \(\sin{ ( \phi ) }\text{.}\) Since \(\sin^2{ ( \phi )} + \cos^2{ ( \phi ) } =1\text{,}\) we have \(\sin^2{ ( \phi ) } + \left( 0.7087 \right)^2 = 1\)\(\sin^2{ ( \phi ) } = 1 - \left( 0.7087 \right)^2\)\(\sin{ ( \phi ) } = \pm \sqrt{0.4977} \approx \pm 0.7055\) . Since \(3 \pi /2 \leq \phi \leq 2 \pi\text{,}\) \(\sin{ ( \phi ) }\) is negative, so \(\sin{ ( \phi ) } \approx - 0.7055\text{.}\) b) \(\tan{ ( \phi ) }= \frac{ \sin{ ( \phi )}}{\cos{ ( \phi )}} = \frac{- 0.7055}{0.7087} \approx -0.9955\)
