Activity 3.2.2.

For each of the following functions, without using graphing technology, determine whether the function is

  1. always increasing or always decreasing;

  2. always concave up or always concave down; and

  3. increasing without bound, decreasing without bound, or increasing/decreasing toward a finite value.

In addition, state the \(y\)-intercept and the range of the function. For each function, write a sentence that explains your thinking and sketch a rough graph of how the function appears.

  1. \(\displaystyle p(t) = 4372 (1.000235)^t + 92856\)

  2. \(\displaystyle q(t) = 27931 (0.97231)^t + 549786\)

  3. \(\displaystyle r(t) = -17398 (0.85234)^t\)

  4. \(\displaystyle s(t) = -17398 (0.85234)^t + 19411\)

  5. \(\displaystyle u(t) = -7522 (1.03817)^t\)

  6. \(\displaystyle v(t) = -7522 (1.03817)^t + 6731\)
