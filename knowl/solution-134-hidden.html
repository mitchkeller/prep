SOLUTION This function resembles a cosine curve in that it attains its maximum when \(x = 0\text{.}\) We know that the smallest value it attains is \(0\) and that its maximum value is \(8\text{.}\) Therefore its midline is \(y = \frac{ 8 + 0}{2} = 4\text{,}\) and its amplitude is \(8 - 4 = 4\text{.}\) Thus in the equation \(f(x) = A \cos{(Bx)} + k\) we know that \(A = 4\) and \(k = 4\text{.}\) Since the graph has a period of \(8\text{,}\) the value for \(B = \frac{2 \pi}{\mbox{period}} = \frac{2 \pi}{8} = \frac{\pi}{4}\text{.}\) Finally we have a formula:
\begin{equation*} f(x) = 4+4 \cos{ \left( \frac{\pi}{4} \ x \right)}. \end{equation*}
