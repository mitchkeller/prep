Solution 5.4.5.2.1.

SOLUTION For the function \(f(x)\text{,}\) \(f(x) \to 1\) as \(x \rightarrow \pm \infty\) since for large values of \(x\text{,}\) \(f(x) \approx \frac{x^3}{x^3}=1\text{.}\) The function \(g(x)\) will behave like \(y= \frac{x^2}{x^3}= 0\) for large values of \(x\text{.}\) Thus, \(g \rightarrow 0\) as \(x \rightarrow \pm \infty\text{.}\) The function \(h(x) \approx \frac{x^4}{x^3} = x\) for large values of \(x\text{.}\) Thus, as \(x \rightarrow \pm \infty\text{,}\) \(h(x)\) approaches the line \(y=x\text{.}\)
