  • Given real numbers \(a\text{,}\) \(b\text{,}\) and \(c\) with \(a \ne 0\text{,}\) the functions

    \begin{equation*} k(t) = a\cos(t-b)+c \text{ and } h(t) = a\sin(t-b) + c \end{equation*}

    each represent a horizontal shift by \(b\) units to the right, followed by a vertical stretch by \(|a|\) units (with a reflection across the \(x\)-axis if \(a \lt 0\)), followed by a vertical shift of \(c\) units, applied to the parent function (\(\cos(t)\) or \(\sin(t)\text{,}\) respectively). The resulting circular functions have midline \(y = c\text{,}\) amplitude \(|a|\text{,}\) range \([c-|a|,c+|a|]\text{,}\) and period \(p = 2\pi\text{.}\) In addition, the anchor point \((b,a+c)\) lies on the graph of \(k\) and the anchor point \((b,c)\) lies on the graph of \(h\text{.}\)

  • Given a function \(f\) and a constant \(k \gt 0\text{,}\) the algebraic transformation \(h(t) = f(kt)\) results in horizontal scaling of \(f\) by a factor of \(\frac{1}{k}\text{.}\) In particular, when \(k \gt 1\text{,}\) the graph of \(f\) is compressed toward the \(y\)-axis by a factor of \(\frac{1}{k}\) to create the graph of \(h\text{,}\) while when \(0 \lt k \lt 1\text{,}\) the graph of \(f\) is stretched away from the \(y\)-axis by a factor of \(\frac{1}{k}\) to create the graph of \(h\text{.}\)

  • Given any circular periodic function for which the midline, amplitude, period, and an anchor point are known, we can find a corresponding formula for the function of the form

    \begin{equation*} k(t) = a\cos(k(t-b))+c \text{ or } h(t) = a\sin(k(t-b)) + c\text{.} \end{equation*}

    Each of these functions has midline \(y = c\text{,}\) amplitude \(|a|\text{,}\) and period \(P = \frac{2\pi}{k}\text{.}\) The point \((b,a+c)\) lies on \(k\) and the point \((b,c)\) lies on \(h\text{.}\)
