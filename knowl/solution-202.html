Solution 4.2.5.4.1.

SOLUTION a) We begin by using the Pythagorean Identity to find \(\sin{ ( \phi ) }\text{.}\) Since \(\sin^2{ ( \phi )} + \cos^2{ ( \phi ) } =1\text{,}\) we have \(\sin^2{ ( \phi ) } + \left( 0.8347 \right)^2 = 1\)\(\sin^2{ ( \phi ) } = 1 - \left( 0.8347 \right)^2\)\(\sin{ ( \phi ) } = \pm \sqrt{0.3033} \approx \pm 0.5507\) . Since \(3 \pi /2 \leq \phi \leq 2 \pi\text{,}\) \(\sin{ ( \phi ) }\) is negative, so \(\sin{ ( \phi ) } \approx - 0.5507\text{.}\) b) \(\tan{ ( \phi ) }= \frac{ \sin{ ( \phi )}}{\cos{ ( \phi )}} = \frac{- 0.5507}{0.8347} \approx -0.6598\)
