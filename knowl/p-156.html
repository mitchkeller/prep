We start with the abstract function \(y = f(x) = -16x^2 + 32x + 48\text{.}\) Absent a physical context, we can investigate the behavior of this function by computing function values, plotting points, and thinking about its overall behavior. We recognize the function \(f\) as quadratic 5 , noting that it opens down because of the leading coefficient of \(-16\text{,}\) with vertex located at \(x = \frac{-32}{2(-16)} = 1\text{,}\) \(y\)-intercept at \((0,48)\text{,}\) and with \(x\)-intercepts at \((-1,0)\) and \((3,0)\) because

\begin{equation*} -16x^2 + 32x + 48 = -16(x^2 - 2x - 3) = -16(x-3)(x+1)\text{.} \end{equation*}
