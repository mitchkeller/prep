Solution 4.5.5.3.1.

SOLUTION

(a) We begin by using the identity \(1 + \tan^2(\theta) = \sec^2(\theta)\) to find \(\sec(\theta).\)

\begin{equation*} \begin{array}{rcl} 1 + \tan^2(\theta) \amp = \amp \sec^2(\theta) \\[1ex] 1 + \left( \frac{-2}{3} \right)^2 \amp = \amp \sec^2(\theta) \\[1ex] \pm \sqrt{ \frac{13}{9} } \amp = \amp \sec(\theta). \end{array} \end{equation*}

Since \(\frac{3\pi}{2} \le \theta \le 2\pi\text{,}\) \(\sec(\theta ) = \frac{1}{\cos(\theta)} \ge 0\text{,}\) and thus \(\sec(\theta) = \sqrt{ \frac{13}{9} } = \frac{\sqrt{13}}{3}.\)

(b) Since \(\tan(\theta) = \frac{ \sin(\theta) }{ \cos(\theta) } = \sin(\theta) \sec(\theta)\text{,}\) we have

\begin{equation*} \sin(\theta) = \frac{ \tan(\theta) }{ \sec(\theta) } = \frac{ -2/3 }{ \sqrt{13} / 3 } = \frac{-2}{\sqrt{13}}. \end{equation*}
