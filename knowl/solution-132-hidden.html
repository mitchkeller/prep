SOLUTION Since the maximum value of the cosine function is \(1\) and the minimum is \(-1\text{,}\) the expression \(-6 \cos{(7 \pi x + 2 )}\) varies between \(- 6\) and \(6\) in value. The subtraction of 9 means that
\begin{equation*} y = -6 \cos{(7 \pi x + 2)} - 9 \end{equation*}
varies between \(-15\) and \(-3\text{.}\) The expression \(7 \pi x + 2\) inside the cosine function is a horizontal compression which affects the period and a phase shift left 2 units. The phase shift left 2 units does not change the period, amplitude or the midline. (a) The period is equal to \(\frac{ 2 \pi}{7 \pi} = \frac{2}{7}\text{.}\) (b) The midline is the average value, \(\mbox{midline} = \frac{ -3 - 15}{2} = -9\) which can be determined by glancing at the coefficient added (subtracted) to the end of expression \(-6 \cos{(7 \pi x + 2 )}\text{.}\) (c) The amplitude is the variation from the midline to the maximum or minimum. In this example \(\mbox{amplitude} = -3 - (-9) = 6\text{.}\) This can quickly be determined by taking the absolute value of the coefficient \(-6\) in front of the cosine in the function
\begin{equation*} y = -6 \cos{(7 \pi x + 2)} - 9\text{.} \end{equation*}
