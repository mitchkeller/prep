The PreTeXt source code for the text can be found on GitHub 13 . If you find errors in the text or have other suggestions, you can file an issue on GitHub or email the author directly. To engage with instructors who use the text, we maintain both an email list and the Open Calculus blog 14 ; you can request that your address be added to the email list by contacting the author. Finally, if you're interested in a video presentation on using the similar Active Calculus text, you can see this online video presentation 15  to the MIT Electronic Seminar on Mathematics Education 16 ; at about the 17-minute mark, the portion begins where we demonstrate features of and how to use the text.
