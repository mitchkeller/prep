Exercise 6.

For each of the following claims, determine whether the statement is true or false. If true, write one sentence to justify your reasoning. If false, give an example of a value that shows the claim fails.

  1. For any \(y\) such that \(-1 \le y \le 1\text{,}\) \(\sin(\arcsin(y)) = y\text{.}\)

  2. For any real number \(t\text{,}\) \(\arcsin(\sin(t)) = t\text{.}\)

  3. For any real number \(t\text{,}\) \(\arccos(\cos(t)) = t\text{.}\)

  4. For any \(y\) such that \(-1 \le y \le 1\text{,}\) \(\cos(\arccos(y)) = y\text{.}\)

  5. For any real number \(y\text{,}\) \(\tan(\arctan(y)) = y\text{.}\)

  6. For any real number \(t\text{,}\) \(\arctan(\tan(t)) = t\text{.}\)
