Solution 4.2.5.5.1.

SOLUTION (a) Using the Pythagorean Identity \(\sin^2{ ( \theta )} + \cos^2{ ( \theta ) } =1\text{,}\) we can solve for \(\cos{ ( \theta )}\text{:}\)
\begin{equation*} \cos^2{ ( \theta ) } = 1 - \sin^2{ ( \theta ) } = 1 - \left( \frac{x}{8} \right)^2 = \frac{ 64 - x^2}{64}. \end{equation*}
Since the angle \(\theta\) is in the first quadrant, \(\cos{ ( \theta ) } \ge 0\text{,}\) so \(\cos{ ( \theta ) } = \sqrt{ \frac{ 64 - x^2}{64} }\) (b) \(\tan{ ( \theta ) } = \frac{ \sin{ ( \theta )}}{\cos{ ( \theta )}} = \frac{\frac{x}{8}}{\sqrt{\frac{ 64 - x^2}{64}} } = \frac{x}{\sqrt{64 - x^2}}\)
