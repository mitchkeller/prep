SOLUTION Since the diameter is 40 meters, your height would be 20 meters when you are halfway up the ferris wheel, so the midline is \(y = k = 20\text{.}\) Your maximum height is 40 meters, so the amplitude is \(A = 20\text{.}\) The period is 8 minutes, so the constant \(B = \frac{ 2 \pi}{8}\text{.}\) At \(t = 0\text{,}\) the 9 o'clock position would be halfway up the ferris wheel. We want the graph to be at its midline when \(t = 0\text{,}\) so we want to use the sine function. We also want the graph to begin decreasing at a first since the ferris wheel is descending, so we need to use a function of the form \(f(t) = -A \sin{(Bt)} + k\text{:}\)
\begin{equation*} f(t) = -20 \sin{\left( \frac{2 \pi}{8} \ t \right)}+20. \end{equation*}
