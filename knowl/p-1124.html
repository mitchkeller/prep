So far, we have seen the possible effects of adding a constant value to function's output (that is, the new expression \(f(x)+a\) if given \(f(x)\)) and adding a constant value to function input (that is, the new expression \(f(x+b)\text{,}\) given \(f(x)\)). Each of these actions results in a translation of the function's graph (either vertically or horizontally), but otherwise leaving the graph the same. Next, we investigate the effects of multiplication the function's output by a constant.
