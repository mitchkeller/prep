More formally, recall that a function \(y = f(x)\) (where \(f : A \to B\)) has an inverse function if and only if there exists another function \(g : B \to A\) such that \(g(f(x)) = x\) for every \(x\) in \(A\text{,}\) and \(f(g(y)) = y\) for every \(y\) in \(B\text{.}\) We know that given a function \(f\text{,}\) we can use the Horizontal Line Test to determine whether or not \(f\) has an inverse function. Finally, whenever a function \(f\) has an inverse function, we call its inverse function \(f^{-1}\) and know that the two equations \(y = f(x)\) and \(x = f^{-1}(y)\) say the same thing from different perspectives.
