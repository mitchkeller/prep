Solution 1.3.4.5.1.

SOLUTION The average rate of change of a function \(f(x)\) over an interval \(a \leq x \leq b\) is computed using the following formula:
\begin{equation*} \mbox{Average Rate of Change of f(x) over } a \leq x \leq b = \frac{ \Delta f }{\Delta x} = \frac{ f(b) - f(a)}{b-a} \end{equation*}
a) Using the formula above with the endpoints (2.2, 2.9) and ( 6.1, 4.9 ) we obtain the following answer:
\begin{equation*} \mbox{Average Rate of Change of f(x) over } 2.2 \leq x \leq 6.1 = \frac{ 4.9 - 2.9}{6.1 - 2.2} = \frac{ 2}{3.9} \end{equation*}
b) Using the formula above with the endpoints (2.2, 2.9) and ( 6.1, 4.9 ) we obtain the following answer:
\begin{equation*} \mbox{Average Rate of Change of g(x) over } 2.2 \leq x \leq 6.1 = \frac{ 4.9 - 2.9}{6.1 - 2.2} = \frac{2}{3.9} \end{equation*}
