Solution 5.4.5.5.1.

SOLUTION Note that \(\displaystyle f(x) = \frac{x^2-16}{-x^3 - 16 x^2} = \frac{(x-4)(x+4)}{-x^2(x+16)}\text{.}\) The \(x\)-intercepts occur when \(y = 0\text{.}\) This will be when \(x = \pm 4\text{.}\) The \(y\)-intercepts are when \(x = 0\text{,}\) but this makes the function undefined, so there are no \(y\) intercepts. Then, vertical asymptotes occur when the denominator goes to zero. This occurs when \(x = 0\) or \(x = -4\text{.}\) Finally, a horizontal asymptote is seen as \(x\to\pm\infty\) if \(f(x)\) has a limiting value there. In this case, as \(x\to\pm\infty\text{,}\) we see that the denominator grows as \(x^3\) while the numerator grows as \(x^2\text{.}\) Thus \(f(x)\to 0\text{,}\) and this is the horizontal asymptote.
