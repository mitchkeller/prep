Solution 5.5.4.1.1.

SOLUTION (a) The graph shows \(y= 1/x\) shifted to the left 1 and up 2 units. Thus,
\begin{equation*} y = \frac{1}{x + 1}+2 \end{equation*}
is a choice for a formula. (b) The equation
\begin{equation*} y = \frac{1}{x + 1}+2 = \frac{ 2 x + 3}{x+1}. \end{equation*}
(c) We see that the graph has both an \(x\)-and \(y\)-intercept. If \(y=0\) then \(2 x+3=0\text{,}\) so \(x= -\frac{3}{2}\text{.}\) The \(x\)-intercept is \(\left( -\frac{3}{2}, 0 \right)\text{.}\) When \(x=0\text{,}\)
\begin{equation*} y= f(0) = \frac{ 2 (0) + 3}{0+1} = \frac{3}{1}, \end{equation*}
so the \(y\)-intercept is \(\left( 0, 3 \right)\text{.}\)
