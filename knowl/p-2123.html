In the situation where \(a \lt 0\text{,}\) several other changes are induced. Here, because \(g(t) = ab^t\) is both a reflection of \(f(t) = b^t\) across the \(x\)-axis and a vertical stretch by \(|a|\text{,}\) the function \(g\) is now always concave down. If \(0 \lt b \lt 1\) so that \(f\) is always decreasing, then \(g\) (the reflected function) is now always increasing; if instead \(b \gt 1\) so \(f\) is increasing, then \(g\) is decreasing. Finally, if \(a \lt 0\text{,}\) then the range of \(g(t) = ab^t + c\) is the set of all real numbers \(c\text{.}\)
