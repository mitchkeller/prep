Activity 3.4.4.

Solve each of the following equations for the exact value of the unknown variable. If there is no solution to the equation, explain why not.

  1. \(\displaystyle e^t = \frac{1}{10}\)

  2. \(\displaystyle 5e^{t}=7\)

  3. \(\displaystyle \ln(t) = -\frac{1}{3}\)

  4. \(\displaystyle e^{1-3t} = 4\)

  5. \(\displaystyle 2\ln(t) + 1 = 4\)

  6. \(\displaystyle 4 - 3e^{2t} = 2\)

  7. \(\displaystyle 4 + 3e^{2t} = 2\)

  8. \(\displaystyle \ln(5 - 6t) = -2\)
