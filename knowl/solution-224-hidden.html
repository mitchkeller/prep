SOLUTION (a) Using the Pythagorean Identity \(\sin^2{ ( \theta )} + \cos^2{ ( \theta ) } =1\text{,}\) we can solve for \(\cos{ ( \theta )}\text{:}\)
\begin{equation*} \cos^2{ ( \theta ) } = 1 - \sin^2{ ( \theta ) } = 1 - \left( \frac{x}{7} \right)^2 = \frac{ 49 - x^2}{49}. \end{equation*}
Since the angle \(\theta\) is in the first quadrant, \(\cos{ ( \theta ) } \ge 0\text{,}\) so \(\cos{ ( \theta ) } = \sqrt{ \frac{ 49 - x^2}{49} }\) (b) \(\tan{ ( \theta ) } = \frac{ \sin{ ( \theta )}}{\cos{ ( \theta )}} = \frac{\frac{x}{7}}{\sqrt{\frac{ 49 - x^2}{49}} } = \frac{x}{\sqrt{49 - x^2}}\)
